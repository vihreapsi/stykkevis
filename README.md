# Stykkevis
***(dev)***

is a digital PWL string generator from a binary sequence or multiple binary sequences separated by comma.

# How to use
provide to the binary these parameters:
- vl: voltage low (in volts)
- vh: voltage high (in volts)
- tr: time of rising edge
- tf: time of falling edge
- tu: time unit (for tr and tf)
- pfx: prefix or prefix schema. Each string of binary sequence will be prefixed with the prefix or the prefix schema. The schema is defined by including '@' character, then the character will be replaced by letters A to Z on each binary sequence.
